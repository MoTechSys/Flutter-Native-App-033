# كِتابي v1.0.0 — ملاحظات الإصدار

**التاريخ:** 2026-09-09 · **الحزمة:** `com.kitabibookstore.books` · **versionCode:** 1

## ما الجديد (الإصدار الأول)
- **متجر كتب كامل بتصميم "مكتبة ليلية فاخرة"**: كحلي فحمي `#12161F` + جوز خشبي + ذهب مصقول `#D4AF37` + عاجي، عناوين Serif، رفّ خشبي في الرئيسية، شريط تبويبات سفلي بأربعة تبويبات.
- **24 كتاباً حقيقياً** في 6 تصنيفات (روايات، تطوير الذات، تقنية وبرمجة، تاريخ، أطفال، علوم) بعناوين ومؤلفين حقيقيين وأوصاف دقيقة وأسعار تقريبية، تُبذر تلقائياً في SQLite عند أول تشغيل بعد التثبيت في مسار قواعد البيانات الافتراضي لأندرويد.
- **24 غلافاً مُصمَّماً** (Pillow + libraqm + خط Amiri) بلون التصنيف وإطار ذهبي وعنوان/مؤلف/سنة.
- **الرئيسية ثابتة الارتفاع** بلا تمرير عمودي: رأس + بحث + بانر + شريط تصنيفات + رفّ "اختيارات كِتابي" + شريط "الأعلى تقييماً".
- **زر الرجوع خطوة بخطوة**: `Navigator` مستقل لكل تبويب + `PopScope(canPop:false)`؛ لا يخرج التطبيق فجأة، بل يعود للصفحة السابقة ← الرئيسية ← حوار تأكيد الخروج.
- **البحث والتصفية**: نص فوري، شرائح سعر، تصنيف، ترتيب (الأكثر صلة/السعر/التقييم/الأحدث).
- **السلة**: سحب للحذف، +/−، كوبونات `KITABI10` `READ20` `WELCOME15`، إتمام الطلب داخل Transaction.
- **الطلبات**: قائمة بإحصاءات، تفاصيل بخط زمني (تم الطلب → قيد التجهيز → تم التسليم)، محاكاة التقدّم، إلغاء ما لم يُسلَّم، نسخ رقم الطلب.
- **المراجعات**: إضافة/تعديل/حذف تقييم بالنجوم لكل كتاب (ورقة سفلية بتبويبَي الوصف/المراجعات).
- **المفضلة**: تبديل بالقلب من أي مكان + "أضف الكل إلى السلة".
- **الحساب** (من صورة المستخدم في الرأس بدل القائمة الجانبية): تعديل البيانات، تغيير كلمة المرور، طلباتي، حول التطبيق، تسجيل الخروج، حذف الحساب (Cascade).
- **المصادقة**: تسجيل بتحقق كامل (اسم/بريد/جوال/مدينة/كلمة مرور/تأكيد/موافقة) مع دخول تلقائي بعد التسجيل، دخول، **استعادة كلمة المرور بـ OTP** (Stepper 3 خطوات؛ رمز `XX-XXX`، دقيقتان، 3 محاولات، تهدئة 30 ث، نسخ/إعادة إرسال).
- **ترخيص بعيد** عبر `license.json` في المستودع: مفتوح/مقفول بكود/موقوف نهائياً/بلا اتصال — بنفس سلوك المشروعين السابقين.
- **أيقونة إطلاق متكيّفة** (طبقتا خلفية/مقدمة + legacy) — كتاب مفتوح ذهبي على فحمي، بلا مربعات سوداء.

## الجودة
- `flutter analyze` → **No issues found**.
- `flutter test` → **23 اختباراً ناجحاً** (16 وحدة + 7 واجهة) تشمل CRUD، Transaction، Cascade، 4 حالات الترخيص، OTP، مسار الاستعادة كاملاً، زر الرجوع، عدم وجود Overflow على 360×780.
- فحص بصري آلي (Playwright) لـ 23 شاشة/حالة على 390×820 بدون أخطاء Console.

## إصلاحات أثناء التطوير
- تعارض اسم `Tab` مع Material → `ShellTab`.
- تعارض `Category` مع `foundation.dart` → `hide Category`.
- Overflow في البانر/بطاقة الشبكة/صف بيانات الكتاب/أزرار الوصف → إعادة ضبط الأبعاد واستخدام `Wrap`/`Flexible`.
- `NavigatorPopHandler` كان يترك النظام يخرج عند جذر التبويب → `PopScope(canPop:false)`.
- CORS على الويب بسبب ترويسات Cache-Control → تُحذف على الويب مع معامل كسر كاش في الرابط.
- حقل المدينة في صفّ واحد مع الجوال يفيض على الشاشات الضيقة → سطر مستقل مع `isExpanded`.
