# 06 — خارطة الطريق

> الحالة الفعلية لكل بند في `07_PROGRESS.md`. هنا الخطة ومعايير القبول فقط.

## المرحلة 0 — الأساس (Foundation)
**الهدف:** مشروع + توثيق + محرك حسابات مُختبَر. **لا شاشات حقيقية بعد.**
- [ ] مشروع Flutter، الحزمة `com.sijildebt.ledger`، الحزم، الخطوط
- [ ] مجلد `docs/` كامل
- [ ] `core/money`: Money, Currency, format, Arabic words
- [ ] `core/db`: schema v1 + triggers + AppDatabase (ffi للاختبار)
- [ ] `core/ledger`: LedgerService (record, reverse, balance, statement range) + errors
- [ ] `test/ledger`: ≥ 40 حالة تغطي R1–R10 وحالات الحافة الـ20
- [ ] هيكل الـtheme + AppDrawer + Home بواجهة بيانات وهمية (للمعاينة فقط)
- [ ] أيقونة التطبيق
- [ ] `flutter analyze` = 0، `flutter test` = 100%
**قبول:** الاختبارات خضراء، المعاينة تفتح الرئيسية والقائمة الجانبية.

## المرحلة 1 — MVP قابل للتجربة في محل
- [ ] دخول المستخدم (صور + PIN)، إنشاء المحل أول مرة (Onboarding صوتي)
- [ ] الزباين: قائمة/شبكة، إضافة (صورة، اسم، صوت، هاتف)، صفحة الزبون
- [ ] عملية جديدة (4 خطوات) بالأوراق النقدية + لوحة أرقام + TTS
- [ ] الحركات: قائمة + فلاتر + تفاصيل + عكس (مالك)
- [ ] الرئيسية ببيانات حقيقية + صف آخر الحركات + الاختصارات
- [ ] تذكير واتساب/SMS من صفحة الزبون (قالب افتراضي)
- [ ] نسخة محلية تلقائية يومية إلى `Android/media/.../النسخ_الاحتياطية`
- [ ] شريط تراجع 8 ثوانٍ (= عكس تلقائي بسبب "تراجع المستخدم")
**قبول:** محل حقيقي يستخدمه أسبوعاً بلا فقدان بيانات.

## المرحلة 2 — الاكتمال التجاري
- [ ] تعدد العملات (تفعيل، رئيسية، سعر صرف يدوي، عرض ≈)
- [ ] المتأخرين + تقادم + "ذكّر الكل" + وعد بالدفع
- [ ] التقارير (يومي/أسبوعي/شهري، أعلى 10، أداء العمال)
- [ ] العمال: إضافة/صلاحيات/سجل نشاط/تنبيه المالك عند دفعة كبيرة
- [ ] الرصيد الافتتاحي، المجموعة العائلية، حد الائتمان، قفل الفترة
- [ ] الوضع الداكن، حجم الخط، البصمة، القفل التلقائي
- [ ] التفعيل بالكود + أداة توليد الأكواد (سكربت منفصل للعميل)
**قبول:** قابل للبيع.

## المرحلة 3 — المستندات الرسمية (انظر `09_DOCUMENTS_SPEC.md`)
- [ ] محرك القوالب (layout_json → PDF)
- [ ] 6 أنواع مستندات × 3 قوالب تصميم
- [ ] محرر الترويسة/التذييل بمعاينة حية
- [ ] الحفظ في `المستندات/YYYY/MM/` + حفظ في Download + مشاركة + طباعة
- [ ] سند قبض 80mm للطابعة الحرارية
**قبول:** كشف حساب A4 يطبعه المحل ويوقّعه الزبون.

## المرحلة 4 — السحابة والمزامنة
- [ ] Google Sign-In + Drive appDataFolder
- [ ] نسخة كاملة يومية + استعادة على جهاز جديد (مع نسخة أمان قبل الاستعادة)
- [ ] مزامنة الأحداث بين أجهزة (event log) + تجميد جهاز
- [ ] تصدير/استيراد `.sijil` مشفَّر + Excel
**قبول:** جهازان يعملان أوفلاين يوماً ثم يتزامنان بلا فقد ولا تكرار (اختبار آلي).

## المرحلة 5 — السرعة والتميّز
- [ ] اختصارات أيقونة التطبيق (quick_actions)
- [ ] الضغط المطوّل على صورة الزبون → نافذة سريعة
- [ ] البحث الصوتي (إن توفر أوفلاين مقبول)
- [ ] ملاحظات صوتية + صور فواتير
- [ ] دليل أول تشغيل صوتي 60 ثانية
- [ ] استيراد الدفتر الورقي بالتصوير (OCR — تجريبي)

## المرحلة 6 — الإطلاق
- [ ] APK موقَّع، اختبار على 3 أجهزة رخيصة مختلفة
- [ ] صفحة/فيديو تعريفي بالعربية اليمنية
- [ ] أداة الوكلاء (توليد أكواد بالجملة)
- [ ] سياسة خصوصية بسيطة بالعربية

## ما نقيس به النجاح
- زمن تسجيل حركة لزبون متكرر: **≤ 3 ثوانٍ / ≤ 3 ضغطات**.
- صفر انحراف في `verifyIntegrity()` خلال شهر تشغيل.
- عامل أمي يسجّل حركة صحيحة بدون مساعدة بعد الدليل الصوتي.
