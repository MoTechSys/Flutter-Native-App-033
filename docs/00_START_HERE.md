## قواعد العمل للوكيل
1. **حدّث `07_PROGRESS.md` قبل إنهاء أي جلسة** — ما فعلت، ما بقي، أي شيء مُعلَّق.
2. **أي خطأ واجهته وحللته → `08_ERRORS_AND_LESSONS.md`** فوراً.
3. **أي قرار تصميمي/تقني جديد → أضفه في الملف المناسب مع السبب.** القرارات بدون أسباب تُنسى.
4. `flutter analyze` صفر مشاكل قبل أي commit.
5. اختبارات محرك الحسابات (`test/ledger/`) يجب أن تنجح 100% قبل أي commit يلمس `lib/core/ledger` أو `lib/core/money`.
6. لا `print()`، لا `withOpacity()`، لا `!` بدون تحقق.
7. الأوامر تُنفَّذ من `/home/user/flutter_app` دائماً.

## أوامر سريعة
```bash
cd /home/user/flutter_app
flutter pub get
flutter analyze
flutter test                          # كل الاختبارات

```
