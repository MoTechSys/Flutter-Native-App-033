# 09 — مواصفات المستندات الرسمية (A4 PDF)

> إثبات عملي موجود: `design/pdf_poc_statement.pdf` + `pdf_poc_page1.png/page2.png` — وُلِّد بـ`pdf` package على هذه البيئة.
> الكود المستهدف: `lib/core/docs/`.

## 1. المبادئ
- **مستند حقيقي** (PDF vector) — ليس لقطة شاشة ولا HTML.
- A4 عمودي افتراضياً (595×842 pt)، هوامش 36pt. سند القبض: نصف A4 أو 80mm roll.
- RTL كامل: `MultiPage(textDirection: rtl)`. **الجداول تُعكس أعمدتها يدوياً** (انظر 08_ERRORS #E1).
- الخطوط مُضمَّنة (Tajawal/Amiri) — لا اعتماد على خطوط النظام.
- الأرقام: غربية افتراضياً، خيار عربية-هندية. فواصل آلاف. العملة كرمز بعد الرقم.
- كل مستند: ترويسة تتكرر كل صفحة، تذييل يتكرر، ترقيم "صفحة X من Y".
- بصمة أسفل التذييل: "صدر بواسطة سِجِل — التاريخ والوقت" (قابلة للإخفاء في النسخة المدفوعة).

## 2. الأنواع الستة
| kind | الاسم | المحتوى | الصفحات |
|---|---|---|---|
| `statement` | كشف حساب مختصر | بيانات الزبون • الرصيد الافتتاحي للفترة • إجمالي أخذ • إجمالي دفع • تسويات • الرصيد الختامي • توقيعان | 1 |
| `statement_detailed` | كشف حساب تفصيلي | + جدول كل حركة: التاريخ، البيان، عليه، له، الرصيد الجاري • (اختياري: العامل، الوقت، المُلغى مشطوباً) | متعدد |
| `receipt` | سند قبض | رقم السند • التاريخ • استلمنا من • مبلغ رقماً وكتابةً • عن (البيان) • الرصيد بعد الدفع • توقيع المستلم | نصف A4 / 80mm |
| `claim` | إشعار مطالبة | رسالة رسمية: "نفيدكم بأن رصيدكم المستحق … نأمل السداد خلال … " • جدول مختصر • بيانات التواصل | 1 |
| `overdue_report` | تقرير المتأخرين | جدول: الزبون، الهاتف، الرصيد، آخر دفعة، أيام التأخر، الفئة (30/60/90+) • إجماليات • للمالك | متعدد |
| `debt_ack` | إقرار بالدين | "أقر أنا … بأن في ذمتي لصالح … مبلغ … وأتعهد بالسداد …" • فراغات للاسم/الهوية/التاريخ • شاهدان • توقيع | 1 |

## 3. القوالب الثلاثة (Design Presets)
| id | الاسم | الشعار | الألوان | الخط | الاستخدام |
|---|---|---|---|---|---|
| `classic` | كلاسيكي | يمين | أسود/رمادي، خطوط رفيعة | Amiri | محلات تقليدية، إقرارات |
| `modern` | حديث | وسط | شريط بلون المحل (افتراضي زمردي) | Tajawal | افتراضي — كما في POC |
| `compact` | مضغوط | صغير يمين | بلا ألوان، هوامش 24pt، خط 9 | Tajawal | توفير حبر/ورق |

## 4. `layout_json` — المخطط
```json
{
  "preset": "modern",
  "page": { "size": "A4", "orientation": "portrait", "margin": 36 },
  "header": {
    "logo": { "show": true, "position": "center", "size": 64 },
    "fields": ["shop_name", "address", "phone", "extra_line"],
    "title_font_size": 18,
    "accent_color": "#0B5D48",
    "divider": true
  },
  "footer": {
    "text": "البضاعة المباعة لا تُرد ولا تُستبدل",
    "page_numbers": true,
    "issued_at": true,
    "brand_stamp": true
  },
  "table": {
    "columns": ["date", "description", "debit", "credit", "running_balance"],
    "show_worker": false, "show_time": false, "show_reversed": false,
    "zebra": true, "font_size": 9.5
  },
  "numerals": "western",
  "signatures": ["shop", "customer"]
}
```
- `position`: `right | center | left | none`.
- `fields` ترتيب الظهور. حقل `extra_line` نص حر (مثل "سجل تجاري رقم …").
- المحرر في التطبيق يعدّل هذا JSON عبر عناصر تحكم (لا يرى المستخدم JSON).

## 5. محرر الترويسة (شاشة)
- الأعلى: **معاينة A4 حية** (صورة مُصغَّرة تُعاد توليدها عند كل تغيير — `Printing.raster` أو `pdf` → صورة).
- الأسفل: تبويبات **الترويسة / التذييل / الجدول / عام**.
- زر "حفظ كقالب" باسم • "استعادة الافتراضي" • "تعيين كافتراضي لـ<kind>".

## 6. التسمية والحفظ
- المسار: `Android/media/com.sijildebt.ledger/سِجِل/المستندات/YYYY/MM/`
- الاسم: `<kind_ar>_<اسم الزبون>_<YYYY-MM-DD>_<HHmm>.pdf` مثال: `كشف_تفصيلي_أحمد_صالح_2026-09-09_1045.pdf`
- بعد التوليد: نافذة بـ4 أزرار كبيرة: **فتح • مشاركة (واتساب) • طباعة • حفظ في التنزيلات**.
- كل توليد يُسجَّل في `audit_log` (entity=`document`).

## 7. الحسابات داخل المستند (تلتزم بـ 04_LEDGER_RULES)
- كشف بفترة `[from, to]`: `opening = balance(< from)`, `closing = opening + Σ(period)`. تُطبع كلتاهما.
- الرصيد الجاري في الجدول يبدأ من `opening`.
- الحركات المعكوسة: إما مخفية (افتراضي) أو ظاهرة مشطوبة مع قيدها العكسي (`show_reversed`).
- كل عملة **جدولها الخاص** داخل الكشف (قسم لكل عملة) — لا جمع.
- المبلغ كتابةً (سند القبض): `numberToArabicWords()` + اسم العملة — نفس الدالة المستخدمة في TTS.

## 8. سند القبض 80mm (طابعة حرارية)
`PdfPageFormat.roll80`، خط 10–12، بلا ألوان، شعار أبيض/أسود صغير، QR اختياري يحمل (رقم السند، المبلغ، التاريخ) للتحقق.
